# Matcher Overview

This repository is the canonical home for the CEMD Python curriculum matcher.

## Active entry point

- Package entry: `src/curriculum_matcher/app.py`
- Convenience runner: `scripts/run_matcher.py`

## Current scope

- Tkinter GUI for local batch runs
- Headless mode for scripted processing
- Hybrid lexical + semantic candidate retrieval
- QA-oriented output with `human_match_*` and `match_#_*` fields

## Archived material

Older GUI variants and Colab experiments now live under `archive/`.
